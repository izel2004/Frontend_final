# LibrarySync - Modern Library Management System

A sleek, modern frontend redesign for the Library Management System with a dark theme and improved UX.

- **Frontend**: https://izel2004.github.io/Frontend_final/
- **Backend API**: https://library2-2.onrender.com


### Complete CRUD Operations
- **Books**: Add, view, edit, delete books
- **Members**: Register, manage, track members
- **Loans**: Create, return, track loans
- **Real-time updates**: Auto-refresh on changes
