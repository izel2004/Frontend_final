# LibrarySync - Modern Library Management System

A sleek, modern frontend redesign for the Library Management System with a dark theme and improved UX.

- **Frontend**: https://izel2004.github.io/Frontend_final/
- **Backend API**: https://library2-2.onrender.com

🛠️ API Endpoints Used
1. Books 
Method	Endpoint	Description	Used In
GET	/api/books	Get all books	Dashboard stats, Books list, Dropdown
GET	/api/books/:id	Get specific book	View book details, Edit modal
POST	/api/books	Create new book	Add Book form
PUT	/api/books/:id	Update book	Edit modal
DELETE	/api/books/:id	Delete book	Delete confirmation

3. Membed
Method	Endpoint	Description	Used In
GET	/api/members	Get all members	Dashboard stats, Members list, Dropdown
GET	/api/members/:id	Get specific member	View member details, Edit modal
POST	/api/members	Create new member	Add Member form
PUT	/api/members/:id	Update member	Edit modal
DELETE	/api/members/:id	Delete member	Delete confirmation

5. Loans
Method	Endpoint	Description	Used In
GET	/api/loans	Get all loans	Dashboard stats, Loans list, Activity feed
GET	/api/loans/:id	Get specific loan	
POST	/api/loans	Create new loan	Create Loan form
PUT	/api/loans/:id	Update loan (mark as returned)	Return loan action
DELETE	/api/loans/:id	Delete loan	Delete confirmation
